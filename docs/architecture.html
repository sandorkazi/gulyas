Architecture & High-Level Diagrams

One task = one git worktree = one Herdr grouped workspace = one Firejail jail, wired to a localhost egress proxy that enforces a domain allowlist and a per-task request budget. Herdr orchestrates. Everything else in this repo confines. This page is self-contained (no external assets) so it renders offline inside the jail.

1 · System context — who trusts whom

Herdr runs unsandboxed on the host (trusted). Only agent processes are jailed. The proxy runs on host loopback (default .venv; Docker is an alternative). Firejail netfilter DROPs direct egress so the proxy is the only way out.

orchestration filesystem jail network policy denied by default

Read it as

  • Herdr never enters the jail; the wrapper stays host-visible so herdr agent list still classifies panes via HERDR_AGENT.
  • Parallel-safe by construction: no shared writable state except the proxy log dir (~/.local/state/herdr-web-proxy/).
  • One proxy per template (ports 8888–8893) because allowlist + budget default differ per template.

2 · Per-task filesystem isolation — what the agent sees

Generated profile + per-instance wrapper flags. The parent ~/.herdr/worktrees is blacklisted, then only the task's own worktree is re-allowed.

Key subtlety

  • --whitelist=$WORKTREE alone does not hide siblings — the parent blacklist is what makes F2 hold.
  • Agent-native deny rules (.claude/settings.json) are a second layer, not the enforcement boundary.

3 · Egress decision flow — every request through the proxy

Netfilter DROPs direct 80/443; loopback to the template port plus DNS (:53) is all that passes. The proxy then applies allowlist → budget → forward, logging before writing so the audit trail cannot be raced.

4 · Budget identity — per-task accounting on a shared template proxy

Stock tools (curl / git / pip / npm) never send custom headers, and CONNECT cannot carry them — so the wrapper encodes BUDGET_ID in the proxy-URL userinfo, which every tool forwards as Proxy-Authorization: Basic ….

5 · Lifecycle sequence — from bootstrap to cleanup

./init.sh ──► .venv + test deps + render templates + symlink profiles/netfilters/allowlists
   │
   ├─► start proxies (ONE per template you use):
   │     .venv/bin/python environment/proxy/src/herdr_web_proxy.py --port 8888 \
   │        --allowlist environment/proxy/config/allowlist.txt --budget-max 200 &
   │
   ├─► herdr worktree create --branch feat/my-task --no-focus     # isolation unit
   ├─► provision-worktree --worktree <WT>                       # .claude/settings.json + AGENTS.md scope
   ├─► herdr-agent-firejail --template default --worktree <WT> \
   │        --budget-id feat-my-task --budget-max 200 -- claude   # jailed agent
   │        │  resolves template → profile/netfilter/allowlist/port
   │        │  encodes budget userinfo → PROXY_URL
   │        │  exec firejail --profile … --blacklist siblings --whitelist $WT …
   │
   └─► done: herdr worktree remove … · proxy --reset <budget-id> · read access.log + herdr pane read

herdr-agent-firejail --list-templates
herdr-agent-firejail --template web --show-template

Audit trail (three legs)

firejail --audit                        # FS denials
~/.local/state/herdr-web-proxy/access.log  # every allow/deny (JSONL)
herdr pane read                         # what the agent saw/did
